# Features
- When the photoresistor is subject to the dark the 2 LEDs in the eyes will turn on and when not the LEDs should stay turned off
- When push button is held down the LED in the mouth will turn on until not held down
- PCB has custom made silkscreen art on front and back
- Pumpkin stem on PCB has exposed FR4 to differentiate it from the pumpkin body and I made a hole through it in order to make it a keychain
